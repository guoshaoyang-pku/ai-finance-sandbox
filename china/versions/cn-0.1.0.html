公司账

现金′ = 现金 + 经营现金流
       − 投入 − 另列付息/租赁 − 到期本金
       + 实际借款 + 出售资产回款

净资产′ = 净资产 + 净利润 − 处置损失
资本支出：先从现金转为资产，不直接扣权益。
支付缺口 ≠ 净资产归零 ≠ 法律破产。

初始银行贷款 = 样本公司银行敞口

             + 城投银行敞口 + 其他贷款

银行资本′ = 资本 + 留存利润 − 新损失 + 注资

本轮数值检查

不能由这个游戏推断什么

不是统计识别出的中国宏观模型，没有估计危机概率。实名公司只用于现金和资产负债压力样本；违约损失率、债务期限、AI占比等均为假设。

初始时点混合：公司2026年6月，宏观存量2026年9月，GDP与财政流量2025年。资产值不按真实季度滚动补齐；2026Q4是合成模拟起点。

银行绝对资本、城投规模、全国AI投资与债务拆分不假装有完整审计数据。GDP、消费、股价均是代理指标，不含通胀、汇率、人口老龄化、完整税制或存款挤兑。

宏观传导是简化反馈模型，不是全经济每笔交易的存量—流量一致清算系统。严重危机后的国家级重组、汇率与资本管制未覆盖，极端尾部结果只能理解为压力失控的信号。

十万亿、百万亿的其他银行损失可以人为施加，但不能把结果说成“AI必然造成了这些损失”。

三个不可混加的量

股票和基金估值下降；银行或债券最终本金损失；未来不可取消的支出承诺。地方债和城投相关贷款也不能与全国贷款总量再相加。
