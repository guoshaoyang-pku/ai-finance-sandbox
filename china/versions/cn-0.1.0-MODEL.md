# 中国 AI 压力沙盘：模型说明

版本 cn-0.1.0。这是基于公开初始数据的条件压力模型，不是拟合后用于预测中国经济的模型。可复现不等于有预测能力。网页中的每条未来曲线都由代码计算；不存在预先写好的危机时间表，也没有设定“某种政策必胜”。

## 1. 范围、时间与单位

以2026Q4为合成起点，每步一季度，默认40季，可延长至60季。公司资产负债表采用2026年6月底，宏观债务采用2026年9月底，GDP及财政流量取2025年全年尺度。没有把这些时点假装成同一日的完整账本，也不把半年的流量当全年数据。

内部金额为万亿元人民币，展示公司账时乘10000转成亿元。价格、工资与名义债务采用固定价格近似，不模拟通胀、汇率或外币偿付风险。无冲击产出路径为 `Ybar(q)=140.1879×1.04^(q/4)`，4%为假设，不是官方预测。

模型包含四家实名公司、其他AI债务项目、城投、银行、地方及额外政策财政、具身股权融资、固定100人的合成城市样本。字节无完整公开账本，明确不填造其净资产、现金与期限。存储制造、国产GPU、算力中心没有单独校准公司账，可能被包含在匿名AI债务假设中，但不能据此推断某家公司的债务。

源代码在 `src/engine.js`；输入事实在 `data/baseline.json`。这不是全国全主体每笔现金都对应清算的存量—流量一致模型，特别是公共融资对手方、商业银行完整负债表和企业间应收应付网络没有展开。

## 2. 外部冲击

Q0—Q3冲击为零，Q4—Q9线性上升，之后按用户设置的半衰期 h 衰减：

```
s(q)=0, q<4
s(q)=(q−3)/6, 4≤q≤9
s(q)=2^(−(q−9)/h), q>9
```

峰值AI回报兑现比例为 r，实际兑现 `ret(q)=1−(1−r)×s(q)`。所以“兑现25%”指冲击峰值，不代表永远25%；持续悲观需要延长冲击半衰期。商业回报与技术采用分开，允许替代岗位继续发生。

市场实际续借系数：

```
roll=clip[1 − 融资冻结×s×(1−0.75×流动性支持) − 0.5×上一季信用缺口, 0, 1]
```

非AI额外银行本金损失单独输入0—100万亿元，从Q4起分8季确认，不每年重复扣同一笔本金。保存已确认外生损失和剩余额度，输出中与其他行业反馈损失可区分。

## 3. 公司：现金账与净资产账

### 初始状态

`可动用资金 C0 = 财报资金池 × 可动用比例`，默认85%。其余资金留在其他资产，不能因不可动用就凭空扣减净资产。不同公司资金池口径并不完全相同。

```
A = C + K_AI + A_other
A = D + L_other + Z + E
```

D为借款债券，Z为夹层权益，E为含少数股东的总权益。初始AI资产是近六季AI资本支出近似，且不超过现金以外资产35%；不是财报披露的AI净资产。AI资本占总购建支出的比例分别假设为阿里80%、腾讯65%、美团20%、小米20%，没有将研发费用再次当作资本支出。

到期计划：流动债务平均分配到未来4季，非流动债务平均分配到第5—24季；新增借款12季到期。没有逐笔债券合同，因此这只是期限压力情景，不能报告现实到期违约日期。

### 经营与投资

财报经营现金流与利润按报告季度数换成季度起点。经营现金流在8季尺度上向“原净利润＋原购建支出的25%”靠拢，靠拢程度默认50%，可改为0以机械延用近期现金流。这是营运资金正常化假设，不是财报推算的确定值。

公司一般规模按2.5%年增长假设增长。国内需求由上一季产出缺口传导，出口部分由外需冲击传导。国内收入份额假设为85%、75%、95%、55%；收入下降向现金利润传导系数为40%、50%、25%、20%。参数不是历史回归结果。

新增AI净资本的假定年现金回报为12%乘实际兑现比例。AI资产按20季衰减；新增损失只在压力超过此前已确认程度时计提，不把同一减值每季重复扣。

全国AI投资计划前4年按10%年增长，之后计划持平。实际投入为计划乘 `(1−0.6×限投)×(1−0.65×信用缺口)×(0.75+0.25×roll)`。这60%为可调整份额，旧合同不全部一键取消。

样本公司AI购建支出使用同一全国投资缩放。企业资金覆盖不足8季/16季时，分别再自愿减少35%/15%的可调整AI支出；可调整份额45%。样本AI支出包含在全国总量中。其他AI项目新借款仅根据“全国实际AI投入减去样本AI投入”计算，避免把样本的资金需求再融资一次。

### 现金、利润与支付缺口

```
C' = C + OCF − 另列必要付款 − Capex − 到期本金
       + 实际续借及新借款 + 资产出售现金
D' = D + 实际借款 − 实付本金
K_AI' = K_AI + 新AI资本支出 − 折旧 − 新减值
E' = E + 净利润 − 资产出售损失
```

额外付款只补财报经营现金流之外的利息、租赁、递延购买对价及模拟新增债务的利息。现有经营现金流已包含的利息不再次扣除。

为了现金流与利润账一致，其他资产使用显式现金—权责发生调整：

```
ΔA_other = 其他资本支出 + (净利润 − 净经营付现 + AI折旧 + AI减值)
```

这是假设的汇总会计调节，不是额外现金，也不是对具体应收账款的预测。所有公司每季检查 A−L−Z−E=0。

资金不足时，可按65%账面回收率出售最多12%的其他资产，处置差额计入权益损失。仍有缺口则记录首次支付缺口，未付本金恢复到债务、其他未付款形成负债；停止该公司继续外推。这样不假装法律重组结果。该公司债权按 `45%+25%×压力` 的未回收比例做一次信用损失假设，其中55%由银行承担。

净资产转负另行记录，不与支付缺口合并。股价下跌不直接减少发行人账面净资产。资本支出不是当期全额亏损。

## 4. 不重复的信用敞口

初始银行贷款283.44万亿元拆分为：

```
样本公司债务 × 55%
+ 其他AI债务 × 65%
+ 城投债务 × 55%
+ 其余贷款（倒算余数）
= 全国贷款起点
```

城投70万亿元、其他AI债务4万亿元、上述债权比例均是假设。它们已经部分包含在贷款总量中，不能再叠加总量。法定地方债60.6539万亿元独立展示，但不是再追加到银行贷款里。

令 g 为上一季对数产出缺口，s为压力，roll为续借率：

```
其他AI季度违约份额 = clip[s×max(0,1−ret)×0.012 + (1−roll)×0.025 + max(0,−g)×0.02, 0, .25]
城投季度违约份额   = clip[土地降幅×s×0.012 + (1−roll)×0.018 + max(0,−g)×0.015, 0, .25]
其他AI未回收比例   = 0.40 + 0.25×s
城投未回收比例     = 0.40 + 0.15×s
```

以上系数未经估计，不是现实违约概率。损失按当季首次违约的尚存本金计算，违约本金从风险池移除。新借款进入新风险池。其他AI新增债务占其当季投入45%，再受债务限制和续借条件约束。城投新增债务每季假设为未违约余额的0.6%乘续借率，不因AI限债按钮而直接削减全部非AI城投融资。

其余贷款除外生损失，还会因需求下降产生 `余额×max(0,−g)×0.004` 的增量损失。未回收比例假设60%。总信用损失分为AI、城投、其他行业、样本公司四项，绝不加上股权损失来冒充银行坏账。

## 5. 银行与信贷

官方资本比率15.26%作为锚；风险加权资产250万亿元为可修改假设，初始资本是二者乘积，不把贷款总额当RWA。

```
资本' = 资本 + 留存利润 − 新信用损失 + 实际注资
RWA' = 初始RWA×(当期贷款/初始贷款)×(1+0.05×融资冻结×压力)
CAR = 资本'/RWA'
资本缺口 = clip[1−CAR/0.12, 0, 1]
信用缺口 = clip[0.8×资本缺口 + 0.12×融资冻结×压力×(1−0.8×流动性支持), 0, .98]
```

模型12%资本目标不是统一法定资本标准。银行季度留存收益采用上半年利润1.2万亿元的一半，再乘60%留存比例、需求及信贷折扣。不把已对应既有风险的损失准备当作额外闲置资本，不将已计提损失核销再扣一次。

资本可以为负，不用下限裁剪掩盖失败。当资本耗尽，后续曲线只是“没有补充重组方案”的压力延续；存款挤兑、银行接管、汇率、资本管制与货币制度变化不在模型中，不应把极端尾部年数当准确预测。

## 6. 地方财政与额外公共融资

地方年度本级一般预算收入12.2082万亿元，土地毛收入4.1518万亿元。土地毛收入只有40%作为可支配财力传导是假设，不把毛额全部当财政利润。

```
季度新增财政缺口 = 本级收入×max(0,1−exp(g))/4
                 + 土地毛收入×土地降幅×压力×40%/4
                 + 地方新增债务×2.70%/4
```

先支付获批地方支持，其余缺口通过地方新增债务和支出削减承担。债务融资份额为 `35%+55%×流动性支持`。支出削减会反馈就业和产出。这是压力相对基线的增量，不是整个财政预算赤字。

额外政策融资用于新增利息、收入补贴、转岗、少量城投担保代偿、银行注资和地方支持。每季融资上限假设2.5%基线GDP，累计新增额上限40%基线GDP；不是中国政府法定财政边界。未获预算的承诺不当作已支付；欠付利息另记。

额外公共融资利率假设2.5%，余额超过基线GDP15%后有增量利率。没有凭空抹去旧债。注资同时取得金融资产，不把全额注资当最终亏损。政策公共融资与地方增量债务合计显示；不含原有中央债务，不能当全国公共债务总额。

## 7. 具身一级市场股权

默认初始累计投入0.2万亿元、年度融资0.16万亿元、前四年年增10%，之后计划融资持平。均为可修改工作情景，非已核验实缴总额。市场融资条件和限投会影响融资兑现。

```
当季融资 = 年度起点/4 × (1+年增速)^(min(q,16)/4)
          × max(.05,roll) × (1−.6×限投) × (1−信用缺口)
当季本金损失 = 尚存股权投入本金 × clip[s×max(0,1−ret)×.04 + (1−roll)×.04,0,.4]
尚存本金' = 尚存本金 + 新融资 − 当季本金损失
```

损失不能超过累计已投入本金。这里不是估值跌幅，不重复计母基金—子基金—企业的同一笔钱。融资流量与当期AI投资支出不直接相加；本版尚不模拟每一基金最终出资人及带担保的回购合同。

## 8. 就业、退出与收入分配

100人的固定合成样本，默认 E0=65、U0由5.2%求职失业率反推、N0=100−E0−U0。5.2%仅采用官方年平均调查失业率作为数值锚；人口比不是国家统计局数据。不把这一组人乘全国人口声称失业人数。

技术采用率初始5%，季度采用速度为 `.025×(.35+.65×sqrt(实际AI投入/计划投入))`，再乘尚未采用比例。无新增投资时仍允许既有、外部技术缓慢采用。

```
AI直接裁员 = 就业人数 × 35%岗位暴露 × 用户替代份额 × 本季采用增量
周期性裁员 = 就业人数 × [max(0,−g)×.003 + 信用缺口×.003 + 地方支出削减×.003]
自然离职 = 就业人数 × .006
自然招聘 = 待业人数 × .11 × exp(2g) × (1−.65×信用缺口)
AI直接新岗位 = AI直接裁员 × 新岗位补回比例
转岗招聘 = 两季前实际转岗支出 ÷ 每个工作者工资尺度 × .25
```

总招聘不超过待业人数；裁员不超过就业人数。超出初始失业量的待业者每季1.8%退出求职，退出者仍在N中；存在缓慢重新参与。始终保持 `E+U+N=100`。工时随需求和信用变化，不能用人数完全替代劳动总量。

普通收入边际消费倾向假设85%，高收入新增收入消费比例默认10%、可调。不能由一部分高收入者的平均储蓄率直接识别边际倾向。消费取决于就业、工时、工资、向高收入群体转移的收入和实际补贴；本版不建立完整家庭财富、房贷或分位收入账。

## 9. 产出反馈与恢复

消费C为相对起点指数（1=起点），Ybar为基线路径。目标对数产出缺口：

```
目标缺口 = −.16×外需降幅×压力
         + .55×(C−1)
         + 1.2×(实际AI投入−计划投入)×4/Ybar
         − 地方被迫减支×4/Ybar + 转岗支出×4/Ybar
         − .12×信用缺口
         + (技术采用率−.05)×max(0,ret)×.035
         − 累积就业损伤

g' = 持续系数×g + (1−持续系数)×目标缺口 + 很小的种子扰动
产出指数 = 100×1.04^(q/4)×exp(g')
```

这些是简化反馈系数，不是实证估计的乘数；网页可对持续系数、冲击半衰期做九组敏感性对比。股价代理仅用于状态输出，`100×exp(2g−.4×融资冻结×压力−.25×(1−ret)×压力)`，不对应任何真实指数点位。

恢复定义：从最大产出缺口的低谷，到第一次连续四季产出偏离基线小于1%的起点。期内未恢复只意味着模拟期内未达到该阈值；不表示永远萧条。低于基线也不表示实际GDP负增长，页面同时显示同比增速。

## 10. 适用边界

本版可以问：“在这组敞口和反馈假设下，同一冲击下哪种政策降低了哪些损失、把代价转给了谁？”不能问：“中国有多少概率在某年萧条、某公司必然哪年破产？”

未估计的参数包括全国AI敞口、银行RWA总量、到期分布、债权持有比例、违约与回收参数、替代速度、招聘和退出速度、收入分配、财政乘数、技术回报。未来研究应替换这些假设、引入实际贷款和债券明细、财政地区拆分及真实劳动转移数据，而不是仅调整参数使结局符合某个观点。
