# cn-0.2.0：月度结算与快速传导

旧版硬编码第4季度起冲击、第9季度峰值，不是实证估计。新版取消隐藏等待，默认第1月启动、第6月峰值，默认传导3倍，独立调整确认期、半衰期、执行滞后。

每步是一个月，而不是缩短播放间隔。季度报告÷3、半年报告÷6、年预算和利息÷12；流动债务仍在12个月分摊，新增借款36个月到期，年度增长仍按年复利。每月转移率=1−(1−季度基准率)^(倍数/3)，月需求持续系数=季度基准系数^(倍数/3)。

默认36个月，选10年/15年可继续；新增同情景1×/3×/6×对照。原始财报金额不变，未强制任何公司在某月破产。旧版和旧存档保持独立，不把40季度解释成40个月。

模型仍未经过历史校准，3倍仅为用户要求重点检验的较快压力情景。快速资金冻结、慢性盈利损耗、债务实际到期是不同机制。
