# 中国 AI 压力沙盘：月度模型 cn-0.2.0

本版针对旧版时间尺度过慢的问题改为月度结算。**3倍传导是压力假设，不是经历史估计得到的真实速度；公司净资产转负和支付缺口仍由账目算出，不指定发生日期。**

## 1. 时间、版本和可比较性

每步一个月，合成起点2026-11；默认36个月，可延长至120/180个月。源码中 `q` 为保留的历史索引，现在表示经过的月份；存档明确标记 `timeUnit: "month"` 和 `month`，CSV第一列也是 `month`。旧版存档不允许静默导入，因为40季度不是40个月；可在 `versions/cn-0.1.0.html` 打开旧季度版。

原始财报数值和来源未在本次修改中重新校准：公司2026年6月，宏观存量2026年9月，GDP与财政流量2025年。混合起点不是真实同日全社会账本。金额内部单位为万亿元人民币，企业表展示乘10000变为亿元；固定价格近似，未建模通胀和汇率。

**时间变细与经济变快是两个改动：**

- 收入、资本支出和必要付款：季度报表流量÷3，半年报流量÷6；年度政策预算÷12。
- 年度增长：`(1+g)^(月数/12)`，不随传导倍数改变。无冲击GDP增长4%、公司规模增长2.5%、前四年计划AI投资增长10%仍是假设。
- 动态转移：给定旧季度概率 p，月概率 `p_m = 1−(1−p)^(v/3)`。v=1保留原季度转移速度，v=3把旧一季度的转移压入一个月。
- 月需求持续系数：`rho_m = rho_q^(v/3)`；原季度默认rho_q=0.75，1倍时每月约0.909，3倍时每月0.75。
- 加速项目：技术采用、压力引致违约、周期裁员、受压退出求职、信贷主动收缩、需求向目标调整。正常离职、自然招聘、重新参与、资产折旧和可出售资产比例仍按原季度速率折成月速率，不自动乘v。
- 冲击启动、上升期、半衰期、外生损失确认期及培训执行滞后分别设置，不再被一个季度步长隐含地绑定。

因此，3倍情景不保证危机或每家公司事件日期严格变成原来的1/3。更快冲击与不变的年收入、融资期限相互作用，产生新的条件结果。

## 2. 外部冲击：取消隐藏的三季度等待

旧版：第4季度开始、第9季度峰值、额外本金损失分8季度确认。新版默认：第1个月开始、从启动起6个月达峰、损失分8个月确认。默认半衰期16个月；极端情景32个月。全部可改。

令 a 为启动月份、r 为上升月数、h 为半衰期，d=m−a+1：

```
s(m) = 0                         m<a
s(m) = d/r                       1≤d≤r
s(m) = 2^(−(d−r)/h)             d>r
AI回报兑现 ret = 1−(1−峰值兑现比例)×s
roll = clip[1−融资冻结×s×(1−.75×流动性支持)−.5×上月信用缺口,0,1]
```

若上升期设为1个月，启动当月就达到峰值。外部冲击峰值不是产出低谷，不是公司破产时点。非AI额外银行损失默认5万亿，极端联合情景30万亿，最大可输入100万亿；总额独立于AI内生损失，按确认期每月扣除，尚未确认总额有独立余额，永不每年重复计算。

## 3. 公司：保留财务期限，不把季度利润当月利润

只纳入四家有原始起点的实名样本；字节不虚构账目。可动用资金等于财报资金池乘默认85%可动用比例，其余仍保留为其他资产。

```
A = C + K_AI + A_other = D + L_other + Z + E
```

夹层权益Z单列。初始AI资产仍用原季度AI购建支出×6（即18个月）估计，且不超过非现金资产35%，不会因时间改成月而错误缩成原来的1/3。AI份额默认阿里80%、腾讯65%、美团20%、小米20%，均是假设，不将研发费用重复算成资本支出。

债务分配依然只是期限假设：流动债务分摊未来12个月；非流动债务分摊第13—72月；新增借款36个月到期。**传导倍数不改变这些期限**，不能当成实际债券兑付表。

经营现金流按报告包含的实际月数折算，按24个月时间常数向“原月净利润+原月购建支出的25%”靠拢，靠拢程度默认50%，可设零；这是营运资金正常化假设。需求减少由上一月产出和当月出口冲击映射到收入、利润和现金流。国内份额依次85%、75%、95%、55%；收入损失向利润传导依次40%、50%、25%、20%，未作历史回归。

新增AI资本的假定年回报12%乘ret，当月现金回报÷12。AI折旧月率为 `1−(1−1/20)^(1/3)`，使一季度末保留95%原资产，不是每个月折旧5%。新增减值仅确认超出此前压力程度的部分。

```
C′ = C + OCF − 另列必要付款 − Capex − 到期本金 + 新借款 + 出售资产回款
D′ = D + 新借款 − 实际偿还本金
K_AI′ = K_AI + AI购建支出 − 折旧 − 新减值
E′ = E + 净利润 − 出售资产损失
ΔA_other = 其他购建支出 + 净利润 − 净经营付现 + AI折旧 + AI减值
```

其他资产调整是现金/权责发生桥接，不能当成额外现金。实际收入和投资会因需求、融资变化内生改变；“年度金额不放大”指单位与预算不机械乘倍数，不表示不同情景实际现金流必须相等。

资金覆盖不足24个月/48个月时自愿缩减可调整AI支出，沿用旧8季度/16季度阈值。资金不足可按65%账面回收率出售其他资产，每月出售上限由旧季度12%换算，不能每个月都凭空获得12%的流动性。仍有缺口则恢复未付本金、记录应付款和首次支付缺口，停止该公司后续外推；不猜法律重组。债权损失假定为未偿余额×(.45+.25s)，55%由银行承担。

净资产转负另行记录；资本支出不是当期全额亏损，股价下跌不是发行人账面净资产等额减少。加速传导不会直接把公司的利润、亏损或净资产改成三倍。

## 4. 投资、债务与银行资本

初始贷款拆成四个不重复的桶：

```
样本公司债务×55% + 其他AI债务×65% + 城投债务×55% + 其余贷款 = 总贷款
```

其他AI债务4万亿、城投70万亿、债权份额均为情景假设；不能再加到全国贷款。默认AI年投资1.6万亿也是假设，按月÷12；计划前48个月按年10%增长，随后计划持平。

```
实际AI投资 = 月计划×(1−.6×限投)×(1−.65×信用缺口)×(.75+.25×roll)
其他AI新增债务 = max(0,全国实际AI投资−样本AI投入)×.45×(1−限债)×roll
```

风险的旧季度基准概率保持显式：

```
p_AI = clip[s×max(0,1−ret)×.012+(1−roll)×.025+max(0,−g)×.02,0,.25]
p_LG = clip[土地降幅×s×.012+(1−roll)×.018+max(0,−g)×.015,0,.25]
当月违约本金 = 尚存本金×[1−(1−p)^(v/3)]
AI信用损失 = AI违约本金×(.4+.25s)
城投信用损失 = 城投违约本金×(.4+.15s)
```

违约本金从旧风险池移除，新借款加入新风险池。其他贷款的需求引致损失也转换为月概率；外生输入损失保持单独总额和确认计划。股权损失不加到信用损失中。

初始银行资本=假设RWA×统计资本比率；RWA不是贷款余额。

```
银行资本′ = 资本 + 当月留存利润 − 新损失 + 当月实际注资
当月留存利润起点 = 半年利润÷6×60%，再受需求和信贷折扣影响
RWA′ = 初始RWA×(当期贷款/初始贷款)×(1+.05×融资冻结×s)
CAR = 资本/RWA
信用缺口 = clip[.8×clip(1−CAR/.12,0,1)+.12×融资冻结×s×(1−.8×流动性),0,.98]
```

12%是模型目标，不是统一法定要求。资本可为负，不裁剪掩盖失败；严重负资本后的持续曲线不含接管、重组、存款挤兑或货币危机，不能解释成真实后果预测。

## 5. 地方财政、政策预算与具身股权

地方本级收入、土地收入和新增债务利息按年尺度÷12；土地毛收入仅40%传入可支配财力。缺口先用地方支持填补，余下按 `35%+55%×流动性支持` 借款，剩余减支。

额外政策公共融资预算每月上限为基线年GDP的10%/12，累计余额上限40%基线GDP；均为假设，不是政府法定约束。银行注资和地方支持年度额度÷12，转岗和收入补贴按年度GDP比例÷12。利息也是年利率÷12。实际支出才能增加公共融资；注资同时取得金融资产，不等于最终损失。城投担保代偿比例由地方支持滑块占其4万亿/年上限的比例决定，这个分母是无量纲归一化，不能错误改成12。

具身初始股权投入0.2万亿、年融资0.16万亿为工作情景。每月计划=年额÷12×前四年的增长因子，再受续融、限投、信用约束。尚存本金的失败概率用同样月概率转换；`尚存本金+累计本金损失=累计投入` 恒成立。不把股权金额直接当银行坏账，不把基金募资、项目投资和公司融资叠加。

## 6. 就业、消费、产出

100人的合成样本，E+U+N=100。就业65%是假设，失业率5.2%作为统计锚；不推全国失业人数。

```
采用季度基准速度 a_q=.025×(.35+.65×sqrt(实际投入/月计划))
当月新增采用 Δa=(1−a)×[1−(1−a_q)^(v/3)]
AI直接替代=E×.35×替代份额×Δa
AI新岗位=直接替代×岗位补回比例
```

压力引致裁员与退出求职使用加速的月概率；正常离职、自然招聘、重新参与用v=1的月概率，避免把全部正常劳动力流量三倍化。招聘不超过待业者，裁员不超过就业者。转岗实际支出经过可调执行滞后（默认2个月）再促进招聘。

消费受就业、工时、工资、收入分配和补贴影响。高收入新增收入消费比例默认10%可调，普通群体85%是假设；观察到的平均储蓄率不能直接识别边际消费倾向。本版没有完整家庭资产负债表。

```
目标缺口 = −.16×外需降幅×s + .55×(消费指数−1)
         +1.2×(实际月AI投资−月计划)×12/年GDP
         −地方月减支×12/年GDP + 月转岗支出×12/年GDP
         −.12×信用缺口 +(采用率−.05)×max(0,ret)×.035 −累积就业损伤
月持续系数 rho_m = rho_q^(v/3)
g′ = rho_m×g + (1−rho_m)×目标缺口 + 小幅种子扰动
产出指数 = 100×1.04^(月数/12)×exp(g′)
```

年度同比比较12个月前，而不是4个月前。恢复时间从最深低谷到首次连续12个月缺口小于1%的起点计算；观察期内没有完整一年证据就显示“期内未恢复”，不是永不恢复。

## 7. 如何比较

政策对照：所有冲击、速度、随机种子和起点相同，仅政策组合不同。速度对照：1/3/6倍，保持冲击启动、上升期、半衰期、确认总额/期数、年预算和原债务期限完全一致，仅改变传导速度。**这不同于将整个旧图横坐标直接除三**，也不强制更快传导必然带来更坏的期末结果。

本次未加入新的现实财务事实。时间尺度差异的研究参照是BIS流动性风险管理关于日内/日度/更长周期的区分，以及美联储SVB回顾中的短期资金外流；它们不用于把中国失业或公司净资产时间常数校准为1/3：

- https://www.bis.org/committees/bcbs/basel-consolidated-guidelines/module/lqy/10
- https://www.federalreserve.gov/publications/2023-April-SVB-Executive-Summary.htm

这仍是解释性反馈模型，不是全经济逐笔现金守恒的清算系统，测试通过仅表明相应单位、会计和功能检查通过。
