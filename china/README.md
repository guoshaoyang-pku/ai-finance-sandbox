# 中国 AI 压力沙盘 / cn-0.1.0

公开数据作起点，可修改假设的季度互动压力测试。默认十年，可延长十五年。

- 公司资金链、地方债、其他AI项目、银行资本、就业与消费。
- 六个外部情景、六种政策组合、季度干预与保存分支。
- 同一冲击的政策对照、九组恢复参数扫描、JSON存档、季度CSV。
- 现金、净资产、股权损失、贷款损失、公共融资分开记录。
- 不虚构字节财报；不发布未证实的公司违法指控；不预测真实破产日期。

## 打开与复现

直接打开 `index.html`。所有运行时资源已内嵌，不依赖第三方脚本、CDN或后台。在线部署在父仓库的 `/china/` 子路径，保留原美国版。

```sh
npm test
npm run build
npm run serve
# http://localhost:8766/
```

`src/engine.js` 是纯JavaScript引擎，Node和浏览器共用。`data/baseline.json` 存放查证数据、口径、日期与来源；`src/app.js` 是界面。保存文件只包含有界参数、种子和政策时间线；导入时重新运行，不执行存档代码。

## 数据与假设

见 [数据说明](docs/DATA.md)、[完整算法](docs/MODEL.md)、[检验记录](docs/VALIDATION.md)。所有来源链接在网页中也可直接访问。

这是解释性压力模拟，不是统计校准后的预测模型。宏观传导不是全经济每笔交易守恒的完整清算系统。会计与数值检查通过不证明经济机制正确；极端银行资本耗尽后的路径不包含重组、挤兑或货币制度改变。
