## 第一优先级：真实资料层，不直接替换虚拟模型

读取 `data/contract.schema.json`。为每条融资/合同建立独立记录，至少包括法律实体双方、原始文件、时点、币种、口径、金额、到期、提款状态、担保/抵押/追索、与其他记录的重叠关系和不确定性。

只从可核验来源提取，优先 SEC、公司财报/招股书、贷款协议和官方投资者资料。保存可公开取得的原文链接与段落定位；禁止绕过访问控制。无法确定最终持有人、担保条件或提款额时保持未知。

合并交易前先检查：同一公告被媒体重复报道；额度与提款；租赁费用与用于融资的本票；母公司与 SPV；存量余额与年度发行流量；债务转售不增加行业债务。不要先把所有数字相加再“校准”。

产出：`data/observed_entities.json`、`data/observed_contracts.json`、`docs/DATA_COVERAGE.md` 和采集/去重测试。现有 `sources.json` 是起点，不是完整数据库。游戏必须保留“虚拟演示”和“已核验数据”分离模式；数据覆盖不足时不开放“真实美国预测”。

## 第二优先级：模型中最重要的缺口

先处理法律偿付顺位、担保代位与递归违约，以及抵押物重复质押。当前主清算按比例，`secured` 不是法律优先级。新增功能必须配微型解析案例：同一抵押物不得被两方同时全额拿走；有担保债权和普通债权的回收不同；担保人失败会产生次级损失；代位请求不重复赔付。

其次区分暂时流动性不足和最终资产不足，加入更明确的重组/延期条件。不得把央行流动性当资本注入。记录每个救助最终由原股东、债权人、担保人、财政还是央行承担。

再改进外部资产需求曲线、银行存款创造/准备金账户，以及银行与基金的贷款资产减值过程。每次仅加入一个机制并做有/无对照，避免不可解释的大改。

## 第三优先级：校准宏观反馈，不扩展伪精确指标

目前宏观系数全部为演示假设。使用有来源的数据估计或给出有理由的区间，保留参数版本、单位、样本期、估计方法和留出检验。必须测试更换季度结算顺序、违约回收率、融资弹性、资产出售弹性和技术收益滞后对结论的影响。

不能把自定义股票组合当真实 S&P/Nasdaq，不能把“政治支持”当民调，不能在没有外汇负债/套保的情况下声称完整模拟跨境汇率传染。财政账户目前是增量子系统，不是美国完整预算。

## agent 可直接调用的接口

```javascript
const E = require('./src/engine');
const w = E.createWorld({
  scenario: 'disappointment', seed: 42,
  severity: 1.5, bankBuffer: 0.04
});
for (let i=0; i<6; i++) E.step(w);
E.setPolicy(w, E.PRESETS.stabilization.policy);
for (let i=0; i<10; i++) E.step(w);
console.log(E.summarize(w));
const saved = E.exportRun(w);
const restored = E.replay(saved); // 从初值和政策日志重算
E.step(restored, {ltv:0.55});
```

`run({policySchedule:{7:patch}})` 表示第 7 季推进前实施 patch；日志保存为 Q6 后的决定。`setPolicy` 当下记录决定，下一次 `step` 才产生经济结果。财政另有审批延迟。

引擎导出保存已经执行的政策历史，不保存 CLI 尚未到达的未来 schedule。浏览器额外 `ui.pendingLate` 保存其内置 Q4 收紧计划；CLI 读取同一文件时只重放已执行历史。需要完整未来计划时，在独立实验配置保存 `policySchedule`，不可假定它会凭空延续。

## 数据与实验的验收条件

每项真实金额有原始来源和时点；未知不写 0；去重有可追溯依据。每项参数明确为观察值、估计值或假设。固定随机种子可复现。政策对照共享外部冲击。可导出全部路径，不能只导出终点。

现金不得无来源增加，债权债务不得单边消失，提款不得超额度，担保不得赔付超过损失和约定上限，注资必须稀释原股东，未来承诺不能当已发放贷款。真实受偿顺位实现后，应单列相应测试，而不是继续复用按比例清算结果。

报告至少保留一个与预期政策结论相反或无效的情景。有限网格命中比例不能称为危机概率；没有分布和样本外验证，不提供“未来危机概率”。
