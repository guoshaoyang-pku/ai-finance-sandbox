# 可玩界面重写 0.3.0

原网址更新：https://guoshaoyang-pku.github.io/ai-finance-sandbox/?v=0.3.0

这次修改的是实际 `src/index.template.html` 和 `src/app.js`，构建出可运行的 `index.html`，不是效果图。原来的金融与人口存量流量引擎保持 0.2.0，39 项已有测试重新执行通过。不能把改界面说成重新校准了美国经济。

## 实际功能

- 五个公司角色直接内嵌在网页，20 个平静、开心、蹙眉、吃瘪表情预览和5个跟随状态按钮。点击角色可查看对应虚拟账目。DeepSeek/Grok仍是观察员，不编造真实企业财务。
- 重新编写暗色响应式界面，人物、就业主指标、金融曲线、政策与资金网络均可交互。手机可横滑角色，操作栏保留下一季与播放。
- 主面板保留 E/P、(U+N)/P、(E+U)/P、U/(E+U) 与总工时。每100人的组成图不会把退出求职者删除；图格按最大余数法舍入，精确数值单列。
- 支持快速开局、16季强替代演示、24季退出求职反例、48季运行。保留新增岗位超过替代岗位的可能，不预设危机。
- 政策未应用状态有明确提示。政府支出由引擎审批/付款，最早Q4加审批滞后。政策对照使用当前游戏的实际初始配置，不误用未应用的表单改动。
- 分支和JSON保存包含表情状态。新增浏览器本地进度保存/读取，重开网页后通过同一引擎重算恢复。导出CSV包括人口和总工时。

## 指标边界

E为就业、U为仍在求职的失业者、N为退出/未参与者；固定P=100、美国16–64岁平民非机构人口。初始比例与转移速度均为假设，不是官方统计。N包含学生、照护者及主动不工作者，未就业占比不是官方U-6，也不全是非自愿失业。BLS定义参考：https://www.bls.gov/cps/definitions.htm 。官方常用全国16岁及以上口径不能直接与本游戏16–64岁假设混用。

## 回归与复现

`npm test`；`npm run build`；`node tests/cli_smoke.js`；`node tests/browser-v030.cjs [https-url]`。浏览器测试需要Playwright，接受PLAYWRIGHT_MODULE和CHROME_PATH。

本地交互检查42项通过，CLI对照5项通过，结果见 local-report.json 与 cli-tests.json；部署后另执行HTTPS检查，报告在test-results/v0.3.0。手机使用Chrome触屏模拟，不是实体Safari。还补回旧仓库遗漏的 examples/config.json 和 examples/policy.json，并让 CLI 回归使用本轮真实浏览器导出的演示结果，不再依赖未随仓库发布的旧结果文件。

首次测试错误地预期Q3已有财政支出，与引擎Q4加审批延迟不符，已改为Q5验证并在界面标明；没有修改经济方程迎合测试。

UI版本0.3.0，计算引擎版本仍0.2.0，兼容0.2.0存档；0.1.x仍须使用旧页面。0.2.0完整页面保留在versions/v0.2.0.html。代码许可不包含上游角色形象；本轮也未重新核验旧版研究资料中的融资金额。
