# v0.3.2 — 公司名称、修正裁剪、继续推演

本次整合了尚未发布的 0.3.1 修改，发布版本为 UI/Engine 0.3.2。

## 公司名代表集体

所有财务主体使用具体公司或机构名，稳定的内部 ID 和数值初始条件不变。主标签是名称，副标签是代表的群体；角色、网络、账目、事件与导出一致。

OpenAI：前沿模型与应用；Anthropic：模型与企业服务；CoreWeave：独立算力云；NVIDIA：芯片与设备；Google：综合科技与云；Salesforce：受 AI 影响的软件与企业服务；JPMorgan Chase / Bank of America：两组大型银行；Apollo：私募信贷；Vanguard：美国长期投资者；挪威主权基金：全球长期投资者；美国财政部和美联储：各自政策账户。

这是一组可读的代表名称，不是行业份额统计。资金规模、股价、债务连接和清算事件仍为假设；尤其不能把网络中的一条边当作这两家真实公司之间存在合同的证据。导出记录内含 representation.notice 与完整映射。DeepSeek、xAI/Grok 仍是观察角色，不因此增加虚构的独立财务账本或中国国内系统。

标普500、纳斯达克、美元等使用常见名称显示；副标题和全局说明明确为模型指数，不是实际行情。没有改变指数方程来冒充真实成分股计算。

## 裁剪修复

原始五列四行图不是严格等尺寸网格，旧的等分裁剪会带入相邻角色边缘。本版使用逐列逐行的实际边界、透明区域连通分析、四周留白和等比例缩放；在浏览器解码成 20 张独立 PNG 图像显示，不再依赖 CSS 背景截取。展示尺寸为 256×284，打包图为 1280×1136。

源图 hash 与裁剪坐标见 assets/characters/crop-map.json。图片是对话生成的同人素材；不是作者原图、官方形象或已核实商用授权。裁剪不是重新生成缺失的头发、衣服或身体，原图半身像的下边界仍是半身构图。

## 48 季是暂停点，不是终点

自动播放与批量推进在 Q48、Q96 等每 48 季检查点暂停。点击“继续推演”、下一季或再次自动播放可以接着推进，保留既有资产负债表、随机冲击、人口状态和政策历史。没有清空再开。已验证 Q48→Q49、Q96→Q97、超 48 季存档重放；六个情景各运行到 Q240 并通过账务和人口检查。

命令行 run/replay 一次最多处理 4000 季是资源保护，不是模型的经济终点；step 继续按需生成确定性随机冲击。Q48 后界面提示固定人口、合同和行为参数尚未长期校准。

## 冲击时间不等于观察窗口

新增 shockStart 和 rampQuarters。默认仍是 Q4 开始、2 季达到设定强度，保留旧模型数值路径。可设 Q1 开始、1 季达到强度；快速演示运行 8 季。时点同步影响冲击、晚收紧政策、财政批准起点、图表竖线与时间提示。

快速演示的第一次企业群体清算出现在 Q2；默认同参数对照在 Q5。这是参数化反事实案例，不是美国危机将在 6 个月或 15 个月内发生的预测。玩家可分别调冲击开始、扩散速度、岗位替代速度和退出求职速度，不能把播放动画速度当作经济速度。

## 测试与边界

本地已运行：54 项引擎/就业/续演/名称测试，56 项桌面与触屏模拟浏览器检查，5 项 CLI/浏览器/重放一致性检查。名称变更有独立测试：六种默认情景的数值 summary 与 0.3.0 所用引擎完全一致。实际线上检查以 test-results/v0.3.2/live-report.json 为准，部署前不能据本地记录声称线上通过。
