## 主指标与人口范围

主指标是就业人数 / 适龄人口，而不是仅看失业人数 / 劳动力。保留劳动参与率，避免把“劳动人口”含义混淆。

本模型固定美国 16–64 岁平民非机构人口，用每 100 人归一化，不假装掌握实际全国人数。BLS 常用全国口径是 16 岁及以上，不能与本版 16–64 岁模拟数值直接比较。初始 E=72.58、U=3.42、N=24 是假设，不是本次抓取的统计数据。

P = E + U + N

E：就业；U：未就业但仍在求职（简化）；N：退出或未参与劳动市场。

就业人口比 = E/P

未就业占比 = (U+N)/P = 1-E/P

劳动参与率 = (E+U)/P

求职失业率 = U/(E+U)；当 E+U=0 时未定义，显示“—”。

总工时指数 = 100×(E×平均周工时)/(初始E×初始周工时)

N 包括学生、照护者、主动不就业者等，不能把全部未就业叫作非自愿失业，也不能称为官方 U-6。未实现 BLS 的全部时间窗、临时解雇和兼职分类。就业人数、总工时不是福利或幸福指数。

概念来源：BLS CPS Definitions，https://www.bls.gov/cps/definitions.htm 。这只是定义来源，不是模型转移率的实证依据。

## 人数转移

每季先更新累计替代比例 a：a←a+s(a目标−a)，a目标由就业替代情景、冲击强度和可替代上限给出。需求岗位数：

J = clip[E0 × (1−a+b×a) × cycle, 0, P]

b 是新增岗位补回比例，允许 0–150%，因此技术进步也可能增加就业。cycle 反映 GDP 相对初始趋势的变化。替代指旧岗位，不是直接设定最终失业率。裁员 E→U、重返求职 N→U、招聘 U→E、退出求职 U→N 都受源人数限制；人数逐季守恒。就业支持必须先实际拨款，才改变招聘和重返求职速度。

平均工时 = 初始工时 × (1−工时缩短比例×a)。劳动收入代理假设每小时实质报酬不变；其变化滞后一季反馈到 GDP，银行外部资产也受劳动投入下降影响。这些弹性全部是假设，不是已估计因果关系。

移除了旧版失业率 2%–30% 截断。比例只受人数恒等式限制，0%–100% 都可表示；没有劳动力时失业率不伪装为零。图表明确分母并支持 0–100% 显示。

## 可复现实验

“演示强替代冲击”：原岗位可替代上限 90%，新岗位补回 10%，每季推进 22%，退出率 12%，平均工时缩短上限 25%；Q16。结果约 E/P=13.92%，未就业占比=86.08%，求职失业率=61.96%，总工时=15.06。不是美国经济预测。

“演示退出求职”：替代上限 85%，退出率 65%，其余同上；Q24。结果约 E/P=12.51%，未就业占比=87.49%，求职失业率仅 2.87%。这个人为极端案例专用于展示：求职失业率低，不保证很多人仍在工作。

另保留新岗位补回 150% 的反例，不能为了讲危机而删除技术带来净新增就业的可能。

## 版本与验证

引擎版本 0.2.0。新老模型经济路径不同，不能沿用 0.1 的数值结果。旧版存档显式拒绝，保留旧 HTML 回放；不会静默迁移后声称完全复现。新版本存档包含劳动参数，导出 CSV 包含人口与工时数据。

运行：`npm test`、`npm run build`、`python tests/browser_v020.py`、`node tests/cli_smoke.js`。容器 Chromium 禁止 file/http 导航时，本地浏览器测试使用 set_content 渲染构建物；真实 HTTPS 测试需独立执行，不能把前者称为线上验收。

当前 39 项引擎/就业测试、24 项浏览器检查、5 项 CLI 检查通过。包括 288 条原金融网格路径和 36 条48季度就业网格路径；有限网格不是危机概率或全域安全证明。手机测试为触屏模拟，不是真机 Safari。

修复过一次 UI 参数步长错误：12% 退出率和22%替代速度不可用5%步长，否则浏览器会静默舍入。现采用1%步长并增加浏览器/CLI一致性断言。
